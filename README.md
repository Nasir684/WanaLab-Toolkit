## VarRho Engine - Formulas - Quick Reference
- VAR: PF = kW/kVA, kVA = kW/PF, θ = acos PF, kVAR = kW*tanθ
- Rho Material: Rho = R*A/L
- Rho Soil Wenner: Rho = 2*π*a*R (ASTM G57)
- Rho Density: Rho = m/V
- Steel: kg/m = Dia²/162 (IS 1786)
- See /varrho-engine/formulas.md for details
