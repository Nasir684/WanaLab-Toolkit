## VarRho Engine - Research Based - Accurate - GitHub
WanaLab Toolkit is based on VarRho Engine - Part of our research at GitHub.
- **VAR - Reactive Power:** VAR = V*I*sinθ, kVAR = kW*tan(acos PF) - IEEE Standard - See /varrho-engine/formulas.md and VALIDATION.md
- **Rho - Resistivity:** Rho = R*A/L, Rho = 2*π*a*R Wenner ASTM G57, Rho = m/V - See /varrho-engine/
- **40 Calculators powered by VarRho Engine** - Accurate - Double precision - Validated with IS, ASTM, IEEE tables - Open for review
- **Validation:** See /varrho-engine/VALIDATION.md - 100% PASS - Research based - Not black box
- **Open for Review:** Students, engineers, universities can verify formulas - Transparent
